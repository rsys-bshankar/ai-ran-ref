index.tsx
Composes sections in a grid. No fetching or logic. Each section sits in its own error boundary.
sections/*.tsx
One box each: owns its query, its five states, and a `data-section` id for logs and tests.
data/queries.ts
The only place that knows API paths, query keys, polling or push topics.
README.md
The section map, each section's API calls and budget, known limits, a troubleshooting checklist and upgrade notes.
__tests__/
A test per section: renders each of the five states, plus an axe check.
Shared
`src/kit/` holds the primitives (ServerTable, Pager, Kpi, ScopePicker…); `src/shell/` holds Sidebar and TopBar.
