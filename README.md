# ai-ran-smo

- **[`specs/`](specs/README.md)** — ground-truth industry specifications
  (3GPP 5G Core OpenAPI, O-RAN O1/O2 YANG and information models) this
  build's design and implementation are grounded against.
- **[`smo/`](smo/README.md)** — the Phase 1 SMO reference implementation
  these specs describe. See `smo/README.md` for the stack, layout,
  quickstart and the documentation map; `smo/OPEN_ITEMS.md` for what
  is still open.
